# Cold-start protocol

Use this protocol to assess a candidate handoff before assignment. Give an
independent agent the package and permitted references, but not the planning
conversation or unstated explanations.

Ask the agent to return:

1. Its understanding of the desired outcome.
2. Scope, non-goals, and constraints.
3. Fixed decisions and implementation flexibility.
4. Dependencies and first implementation actions.
5. Expected evidence and acceptance checks.
6. Questions, missing inputs, and escalation triggers.

Compare the response to the authoritative package. Record mismatches as one of:

- omitted binding context;
- ambiguous instruction;
- conflicting source or decision;
- missing dependency or contract;
- unsuitable abstraction level; or
- expected bounded unknown.

The result is evidence for the readiness evaluator. It does not itself grant
authority or replace deterministic validation.
